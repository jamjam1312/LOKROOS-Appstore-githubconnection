# Roadmap

## Alpha 1 — current

- Native dark Qt/QML browser.
- Offline catalog and icons.
- Search, categories, featured items and project links.
- Safe per-user Flatpak installation and updates.
- Catalog/schema validation, tests and Arch package recipe.

## Alpha 2 — LOKRO OS integration

- Tag and checksum the store source.
- Add a pinned `lokro-store` package to the ISO repository.
- Add the launcher to Plasma and the welcome screen.
- Exercise install/update flows in the ISO VM workflow.
- Add German UI strings.

## Later

- Reviewed `.lokrodesign` submission workflow with preview images.
- Cursor, theme and wallpaper collections using declarative user-scoped packs.
- Optional review service and signed catalog snapshots.
- Ratings or download counts only if a privacy-respecting, auditable backend is
  designed; the static GitHub catalog intentionally has no tracking.
