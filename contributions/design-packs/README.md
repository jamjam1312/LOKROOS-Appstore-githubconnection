# Design-pack submissions

Create one folder named after the proposed reverse-DNS pack ID. Include:

- a link to the checksum-pinned `.lokrodesign` archive;
- `preview.png` or `preview.webp`;
- author, source and license information;
- confirmation that every included asset may be redistributed;
- the output of `lokro-design-pack validate PACK.lokrodesign`.

Do not submit scripts, executables, symlinks, Plasma binary plugins or archives
that download more content. Initial contributions remain pull requests until a
maintainer has reviewed them. Images supplied later by the LOKRO team can use
this exact route.
